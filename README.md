# 🚀✨ Como Deixar Seu README Bonito e Profissional ✨🚀

Aprenda os comandos básicos de Markdown para deixar o README do seu projeto mais organizado e apresentável!

---

## # Títulos

Use `#` para criar títulos:

```md
# Título grande
## Título médio
### Título menor
```

---

## **Negrito** e *Itálico*

```md
**Texto em negrito**
*Texto em itálico*
```

---

## Listas

**Com marcadores:**
```md
- Item 1
- Item 2
- Item 3
```

**Numerada:**
```md
1. Primeiro
2. Segundo
3. Terceiro
```

## Linha divisória

```md
---
```

## Inserir imagem

```md
![Descrição da imagem](link-da-imagem)
```

---

## Inserir link

```md
[Texto do link](https://exemplo.com)
```

---

## Bloco de código

```md
```bash
comando aqui
```
```

---

## Emojis

Use dois-pontos com o nome do emoji:

```md
:rocket: :sparkles: :fire:
```

**Resultado:** 🚀 ✨ 🔥
